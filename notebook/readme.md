
# 📓 Project Notebook

This folder contains the Jupyter Notebook used for **Horizon: Early Detection of Player Disengagement**.

## Contents

- **Online Gaming Player Engagement Analysis** — Data preprocessing, exploratory data analysis, deep learning model training, machine learning model comparison, evaluation, and engagement analytics.

## How to Run

1. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
2. Install the dependencies listed in the root `requirements.txt`.
3. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/rabieelkharoua/predict-online-gaming-behavior-dataset).
4. Update the dataset path if required.
5. Run the notebook cells in order.

## Models

- Multilayer Perceptron (MLP)
- Logistic Regression
- Random Forest
- XGBoost
